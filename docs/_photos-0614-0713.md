## Technical findings

### Machine identity and type plate (IMG_0615)
- Type plate on control box rear: **EMCO PC TURN 50**, "110/230 V; 50/60 Hz; 1/N/PE~; 5,5 A / 2,6 A; 600 W; S1-100 % ED". Made by EMCO MAIER Ges.m.b.H., Hallein/AUSTRIA. Fabr.-No. partly legible (appears "…61 03 001…", see Uncertain). Box labels: "A6M 311 000 06G", "A6M 146 25", "G.E-KASTEN" (= Gerätekasten, equipment box).
- Separate red control box carries: mains keyswitch (with key), **DB9 female** connector (PC serial link), IEC C14 inlet with integral fuse drawer (IMG_0615). Binder B says an incoming-power adjustment "located at fuse holder on right side of machine" must be set to 100 (IMG_0683).

### Control box internals (IMG_0617, IMG_0618)
- Power section (IMG_0617): two ABB **BC6-30-01** contactors, mains transformer tagged **=1DAO.C1-T1**, motor-run capacitor, 4-position fuse bank **=1DAO.M1-F1…F4**, numbered terminal strip 1–14, small EMCO interface PCB ("MADE BY EMCO MAIER", part no. partially legible, Y4A8…).
- Card rack (IMG_0618), three EMCO boards:
  - **Y4A 018 000 STEPMOTORBOARD** (label =1DCO/=1DAO.M1-A1): connectors silkscreened `X4 E-OFF`, `X1 CONTROL INTERFACE`, `X101`, `X301 X-AXIS`, `X501 Z-AXIS`, `X3`, `X201 CONTROL INTERFACE`; LEDs for VCC/ERROR and X-AXIS / Z-AXIS ready. This is the stepper power card the task brief calls Y4A018000 — confirmed.
  - Middle board: POWER SUPPLY / **MD CONTROL** (spindle/main-drive control): `X2000`, `X1000`, `X102`, `X101`, `X111`, `X110 E-OFF / DOOR / SYNC MD`, `X109 MD FEEDBACK`, `X112`, `X113 REF X-AXIS`, `X115–X118`, `SYNC X-AXIS`. Presence of **`X109 MD FEEDBACK` and `SYNC MD`** indicates the main drive has a feedback/sync (tacho or one-per-rev sync) input on this board — relevant to threading (G21/G33 exist in both manuals, which implies at least a spindle sync signal; no separate encoder was seen in any photo).
  - **Y4A 016 000 SPS** (PLC) board (=1DAO.M1-A3): output terminals `X241 A0.0–A0.7`, `X240 A1.0–A1.7`, input terminals `X220 E0.0–E0.7`, `X210/X211/X212/X213` (E1.x–E3.x), `X225` (Vx1 Vx2 +24V GND), plus `X250/X251/X280/X281`, `X221/X222`, `X252`, `X260`, `RESET`, `X10`. These A0.x/E3.x numbers match the robotic-interface signal table below.
- **The AC95 "brain" board (Y4B081000) and its X104 ribbon were not directly identified in any photo** — the community description is neither confirmed nor contradicted by this photo range; the visible `X1/X201 CONTROL INTERFACE` headers on the stepper board are consistent with a ribbon from a controller board.

### Machine technical data (Binder B, IMG_0682 — US-units table)
Values as printed (pairing partly inferred from layout, see Uncertain):
- Working area: longitudinal (Z) travel **8.97 in**?, cross-slide (X) travel **1.88 in** (≈48 mm), distance between centers **11.8 in**, swing over bed **5.0 in**, swing over cross slide **2.36 in** (60 mm).
- Headstock: hole through spindle **0.625 in**, inner spindle taper **#2 MT**, chuck clamping range **0.1–1.125 in**, spindle speed range **130–3000 rpm**, mechanical speed ranges (belt steps) **3**.
- Feed motors: step resolution (smallest positioning movement) **0.0001 in**, feedrates X/Z **0–30 IPM** (infinitely variable), rapid traverse X/Z **30 IPM**.
- Tailstock: quill extension **1.375 in**, taper **#1 MT**.
- Turret: **3 OD stations + 3 ID stations** (6 total), max tool cross-section **0.472 in** (12 mm).
- Gear/belt ranges (Binder A, IMG_0639): gear 1: 130–1300 rpm, gear 2: 200–2000 rpm, gear 3: 300–3000 rpm.

### RS-232 settings (Binder A, IMG_0640; alarm page IMG_0657)
- WinNC/Fanuc-0T serial parameter screen ("PARAMETERS OF SERIAL INTERFACE"): defaults **COM1: 9600 baud, parity E, 1 stop bit, 7 data bits; COM2 same; DNC: 9600, E, 1, 8 data bits; Control parameter 00000001**.
- Allowed values: baud 110, 150, 300, 600, 1200, 2400, 4800, 9600 (startup-alarm page also lists 19200); parity E, O, N; stop bits 1, 2; data bits 7, 8.
- "Data transmission from/to original control in ISO code only: **7 data bits, parity even (=E)**."
- Control parameter bit 0 = 1: transmission cancelled with **ETX** (End of Text) code, else with RESET; option to overwrite part program without message; program end character **% (25H)**.
- I/O device selection (SETTING 3): 1 = COM1, 2 = COM2, A/B = floppy, C = hard disk workpiece directory, P = printer on LPT1.
- No handshaking (RTS/CTS/XON) parameter is exposed on this screen; keyboard cable pinout (below) crosses RTS/CTS.

### PC ↔ machine link (both binders)
- The PC did **not** talk plain RS-232 to the machine: an EMCO **PCCOM ISA interface card** sat in the PC (memory-mapped at CC000–CFFFF, jumpers ST1–ST3 select 2 KB window; free IRQ 3/4/5/7/10/11/12/15) and drove an **RS-485 device bus** to the machine (alarms: "2520/2523 ORD 1 RS485 device absent", "983: RS485 ERROR - INITIALIZING PC BOARD"; RS-485 device list in WinConfig with per-board address switches; devices named AC, SPS, MT, PLC, control keyboard, axis controller in alarm 2521 text) (IMG_0629, IMG_0630, IMG_0658, IMG_0669, IMG_0676, IMG_0683).
- Boot order matters: machine ON and interface cable connected **before** starting the DOS software, else the RS-485-absent alarm (IMG_0683).
- DOS software: `CD\PCNC`, run `FANOT`; programs stored as ASCII in `C:\PCNC\PRG`; "SYSTEM EDITION 0465-15" shown on library screen (IMG_0685, IMG_0688, IMG_0689).

### EMCO control keyboard (accessory, Binder A, IMG_0677, IMG_0679)
- Connects to PC via RS-485 (preferred, via PCCOM board) or RS-232 (COM1/COM2). Ref. no. 795 000 basic case including two cables (RS-232 and RS-485); 795 110 = Fanuc 0 key module; power supply 795 700 (230 V) / 795 710 (115 V).
- RS-232 DB9 pin assignment printed (PC side / keyboard side): 2 TXD, 3 RXD, 5 GND, 7 CTS, 8 RTS (TX/RX and RTS/CTS crossed between PC and keyboard); RS-485 socket: /DATA, DATA, GND (9-pole, male on keyboard). Keyboard supply: 9–14 V AC or DC, ≥250 mA, 5/2.5 mm cinch jack, polarity-free.

### Robotic interface, PC TURN 50 (Binder A, IMG_0662) — the machine's digital I/O
- Inputs/outputs are **NOT potential-free**; signal level HIGH = 20–24 V; outputs short-circuit-proof, 0.2 A max.
- Outputs: A0.0 program stop (M30/M00/M01), A0.1 chuck/collet open, A0.3 chuck/collet closed, A0.4 door open, A0.5 door closed, A0.6 tailstock position, A0.7 alarm.
- Inputs: E3.0 open door, E3.1 close door, E3.2 tailstock backward, E3.3 tailstock forward, E3.4 open chuck/collet, E3.5 close chuck/collet, E3.7 feed stop.
- These terminal names match X241 (A0.x) and X213 (E3.x) on the SPS board photographed in IMG_0618.

### Turret / tool change (Binder B, IMG_0687, IMG_0693, IMG_0698, IMG_0699)
- 6-position turret: 3 external + 3 internal stations, positions stamped on turret face; max tool stickout 0.50 in or it strikes the bed while indexing; recommended: RH turning tool st. 2, threading st. 4, parting st. 6.
- Indexing from the DOS software: **CONTROL+1** indexes the turret one position (operator hand-turns tool into position per procedure!); in MDI, `T0xxx` rotates turret to that station. T-word format T0202 = station 2, offset register 2 (16 registers).
- No powered tool sensing described beyond turret-sync alarms ("6041 tool change timeout — tool turret stucks", "tool turret not locked") in the alarm lists (IMG_0659–0661).

### Spindle
- Spindle: belt-change 3-range drive, 130–3000 rpm, controlled by MD CONTROL board (IMG_0618); MDI accepts `M03 Sxxxx` direct RPM (G97), G96 constant surface speed and G92 spindle limit exist (IMG_0705).
- **Encoder/index question: no discrete spindle encoder was photographed.** Evidence that some spindle feedback exists: `X109 MD FEEDBACK` and `SYNC MD` headers on the MD board (IMG_0618) plus working thread cycles G21/G33/G78 and threading alarms (8194–8211) in both manuals. Whether that is a full quadrature encoder or a one-rev sync sensor cannot be determined from these photos.

### G/M code summaries (Binder B, IMG_0705–0713; EMCO Fanuc-0T dialect, group C)
- G00 rapid; G01 linear; G02/G03 circular (I/K); G04 dwell; **G20 longitudinal turning cycle; G21 thread cutting cycle (F = pitch); G24 facing cycle**; G28 reference return; G33 single-block threading; G40/41/42; **G70 inch / G71 metric data input**; G72 finishing; G73 stock removal turning; G74 stock removal facing; G75 pattern repeat; G76 deep-hole/peck (2-block, R + Q); G77 cut-in X; G78 multiple threading; G80 cancel; G83/84/85 drill/tap/ream; G90 abs; G91 inc; G92 coord set/spindle limit; G94 feed/min; G95 feed/rev; G96 CSS; G97 direct rpm; G98/G99 return planes.
- M00 stop; M01 opt stop; M02 end; M03 CW; M04 CCW; M05 stop; M08/M09 coolant (PC TURN 120)/puff blowing pairs M71/M72 (PC TURN 50); M20/M21 tailstock back/forward; M25/M26 clamping open/close; M30 end+rewind; M98/M99 subprograms.
- Program addresses: O program no. (1–9999), N block, U/W incremental X/Z (also dwell), R radius/taper, I/K circle params, F feed or thread lead, S speed, T tool+offset, P/Q block labels for cycles.

### Homing / offsets procedures (Binder B)
- Reference machine: F1 → F7 (REF), then keypad #5 executes; machine rapids to reference point; machine permanent 0,0 = centerline at spindle front face (IMG_0684–0686).
- Work shift: OFFSET → W.SHIFT; Z shift measured by scraping faced stock (or paper drag on turret face), entered as negative W value; X workpiece zero fixed at spindle centerline (always 0) (IMG_0687–0688, IMG_0700).
- Tool geometry offsets: geometry screen G01–G08 rows hold X, Z, R (nose radius) and T (tip type 1–9); Z from scrape (W value), X from (measured dia − stock dia)/2 style math; example R.060 T3 (IMG_0702–0703).
