## Technical findings

### Identity and control architecture
- Machine: **EMCO PC Turn 50**; control is a DOS PC running EMCO's **"Control System GE FANUC Series 0-TC"** software v2.0 (Edition 1993, Ref. EN 0091); machine-description manual valid from 1.1.1993 [IMG_0769, IMG_0731]. Start-up guide from EMCO Maier Corp, Columbus OH [IMG_0718]. Classroom guide Edition 1995, US 9905, references WinNC v3.10 [IMG_0802, IMG_0803].
- **PC↔machine link is RS-485, not RS-232.** "The interface is a serial interface RS 485 and is used for connecting the computer with the machine." Supplied: proprietary 8-bit ISA "interface card RS485" with **two sockets** — one takes a **terminator ("end") plug**, the other the **9-pole interface cable (RS 485)** to the socket on the machine's electric cabinet [IMG_0740, IMG_0737, IMG_0741, IMG_0736]. Without the card the software raises alarm **"2520 ORDxx RS485 device absent"** [IMG_0790, IMG_0719]. So the DB9 on the red box is the RS-485 drop of this bus; the dead PC's ISA card is required by the original software.
- The ISA card is **memory-mapped, not a COM port**: it occupies a 4 KB dual-port window, default **CC000–CCFFF**, selectable by jumpers ST1/ST2/ST3 over CC000–CFFFF (8 positions, table in IMG_0791); install alarms 2523 "INIT error on RS485 PC-board", 2524 "Gen.-Failure RS485 PC-board" [IMG_0791, IMG_0793]. Software started with command `FANOT` from DOS [IMG_0790]. An EMCO external control keyboard could also sit on the RS485 card (`ET0:adr`, addr 0–15) or on COM1/COM2 (`ET1`/`ET2`) [IMG_0789].
- COM1/COM2 on the PC are only for **program/offset transfer to external devices**, parameters fixed in the software: **9600 baud, ISO code, 7 data bits, parity even** for both COM1 and COM2 (stop bits shown in table but not legible — see Uncertain). F9 = output (EDIT/PRGRM for part programs, OFFSET for tool data; program number 0–9999 sends all), F10 = input; Shift-F1 sets device: 1=COM1, 2=COM2, A/B/C = disk drives; disk import names "PP-IMP" (part programs), "WZ-IMP" (tool data) [IMG_0772, IMG_0786]. RS-232-related alarms: 1 "RS232 parity error" (wrong RS 232 setting in external device), 2 "RS232 transmission error", 9007 data-transmission active, 9012 unknown data type RS232, 9013 error in data RS232, 9018 invalid RS232 configuration [IMG_0792, IMG_0794].

### Technical data (machine-description manual p7, IMG_0735, plus classroom guide)
- Working area: centre height 65 mm; distance between centres 300 mm; swing over bed ø130 mm; swing over cross slide ~ø60 mm; usable cross-slide travel 48 mm (1.89″); usable longitudinal travel 228 mm (8.97″) — mechanical travel 275 mm stated on p16 [IMG_0744]; classroom guide gives Z 10.83″/X 1.89″ traversing paths [IMG_0809]. Max tool section 12×12 mm.
- Headstock: through-hole with shortened MT2 (handwritten .625″); chuck ø90 mm; clamping plate ø130? (see Uncertain); spindle speed 130–3000 rpm in **3 belt steps: 130–1300 / 200–2000 / 300–3000 rpm** [IMG_0750, IMG_0807]. Belt position must be entered in the control software — used for speed monitoring **and for aligning main drive with feed drives when thread cutting** [IMG_0750].
- Main drive: 3-phase AC motor, ~1370 rpm nominal, **370/550 W** (100 %/60 % duty); torque up to ~7 Nm per speed-torque chart [IMG_0735, IMG_0760].
- Feed axes: **step motors** (manufacturer not named anywhere in this range), step resolution 0.001 mm (classroom guide: 0.000098″ ≈ 0.0025 mm minimum travel per p16), working feed 0–750 mm/min (classroom guide 0–30 in/min), rapid/max feed 0–1500 mm/min per p16, max feed force ~600 N [IMG_0735, IMG_0744, IMG_0809].
- Tailstock: sleeve ø22 mm, taper MT1, stroke 35 mm, 1 handwheel turn = 1 mm [IMG_0743].
- Electrics: 100/110/230 V 1/N/PE~ 50/60 Hz, connected load **0.6 kVA**, back-fuse max **6.3 A slow**; ±5/−10 % tolerance; voltage selection by a selector pin at the fuse holder (110 V mains → "100" setting; 230 V → "220"); true 100 V operation requires moving the transformer's blue core wire from "0" to "−5 %" [IMG_0739, IMG_0719].
- Dimensions/weight: 840 × 695 × 345 mm, 85 kg [IMG_0738].

### Axis limits, homing, spindle sensing
- **No axis limit/home hardware described**: p16 states travel is limited only by mechanical stops — an over-travelling step motor stalls audibly ("tack-tack") without damage [IMG_0744]. Reference point R must be re-approached after every power failure / E-stop (REF mode, F7 then 5; REFPOINT mode in classroom guide) [IMG_0773, IMG_0813, IMG_0720]. Alarms 315/325/335 "rotatory checking X/Y/Z — the step motor fell out of step, approach reference point" imply some rotation monitoring on the motors [IMG_0792].
- **Spindle sync mark exists**: alarm 8010 "Sync. error main drive — main drive synchronising mark not found" [IMG_0793], and G33/G78 threading plus the requirement to tell the software the belt position [IMG_0750] imply a **single index/sync sensor on the spindle** (not a full encoder). Threading limited to ≤400 RPM per the start-up guide [IMG_0714]; alarm 8020 fires when thread feed reaches 80 % of max feed [IMG_0793].
- Safety: chip-guard cover and (change-)wheel cover each carry a **limit switch**; EMERGENCY-OFF interrupts power to main and feed motors [IMG_0743]. PLC alarms 6024 "door not closed", 6025 "gearbox cover not closed" correspond [IMG_0793].

### Turret / tool changer
- Optional tool turret: **6 stations (3 external + 3 internal ø10 mm)**; cannot be retrofitted [IMG_0748, IMG_0749]. Driving it from the PC requires an extra **"memory programmable control (SPS/PLC)" card + disk** [IMG_0764]. Turret indexed manually from JOG with Ctrl+I (start-up guide: "CTRL+I") [IMG_0725, IMG_0729]. Turret alarms: 6040 tool-turret failure, 6041 tool-change timeout, 6043–6045 tool-turret sync errors, 7000 wrong tool number [IMG_0793]. Basic machine instead uses a manual quick-change toolpost; tool call format T0404; 16 offset registers (32 optional) [IMG_0774].
- Turret drawing on classroom-guide p8 shows a motor + worm drive on the turret body [IMG_0810].

### Programming (EMCO Fanuc 0T dialect)
- G-codes: G00/01/02/03/04, G20 (longitudinal cycle), G21 (thread cycle), G24 (facing cycle), G28, G33, G40–42, G70 (inch), G71 (metric), G72 (finish), G73/G74 (stock removal turning/facing contour), G75 (pattern repeat), G76 (deep-hole drill), G77 (groove X), G78 (multi-pass thread), G80, G83–G85, G90/91/92/94/95/96/97, G98/99; M00/01/02/03/04/05/30/98/99 [IMG_0727, IMG_0776].
- G78 details: first block `G78 P(2-digit finishing cuts)(2-digit chamfer)(2-digit flank angle) Q(min cut depth µm) R(finish offset)`, second block `G78 X(U) Z(W) R(taper) P(thread depth µm) Q(first cut µm) F(pitch)`; position ≥0.100″ before the thread to synchronize; ≤400 RPM [IMG_0714, IMG_0715, IMG_0782].
- NC programs stored on the PC; DIN 66025 program structure; program/offset transfer as under RS-232 above [IMG_0776, IMG_0786].
- Full alarm list photographed: 1–510 [IMG_0792], 520–9004 [IMG_0793], 9005–9540 [IMG_0794]. PLC alarm groups: 6000 E-stop, 6010/6011/6012 axis not ready, 6013 main drive not ready, 6016/6017 clamp pressure, 6032 main-drive overload, 6033 vacuum-pump overload, 7016 turn on aux drives, 7017 reference, 7040 door open [IMG_0793].

### Consumables / accessories
- Slideway oil ISO VG 68 (CGLP DIN 51 502): BP Maccurat 68, Castrol Magnaglide D 68, Esso Febis K 68 etc.; spindle bearings and recirculating ball screws are maintenance-free [IMG_0756].
- Collet system **ESX 25**, 1.5–14 mm; 3-jaw chuck V3U 176; 4-jaw V3U 178; clamping plate ø90 (200 420); optical presetter 260 060 [IMG_0751, IMG_0753, IMG_0762].

## Uncertain
- **Stop bits in the COM1/COM2 table (IMG_0772)**: baud 9600, parity E, 7 data bits are legible; the stop-bit row could not be read with confidence (looks like 1, possibly 2). Re-check the physical page ("Parameter of serial interface", Chapter A).
- IMG_0735 technical-data rows for "rapid traverse" vs "maximum feed force": I read working feed 0–750 mm/min and max feed force 600 N (valid to 500 mm/min), while p16 says feed speed 0–1500 mm/min. The exact split rapid-vs-working on p7 should be re-verified.
- Swing over cross slide (~ø60 mm) and "clamping plate diameter ø130" on IMG_0735 are low-confidence readings.
- Handwritten phone number on IMG_0718 read (inverted) as 1-800-841-0626 — verify.
- IMG_0730 (softkey menu tree) and IMG_0785 (chamfers/radii) are too blurry to transcribe.
- Whether the spindle "synchronising mark" (alarm 8010) is a one-pulse index or a multi-line encoder is inferred, not stated, in these pages; no encoder spec appears anywhere in this range.
- Berger Lahr / 5-phase stepper attribution, AC95 board Y4B081000, X104 ribbon, stepper card Y4A018000, spindle controller Y4A400000: **nothing in IMG_0714–0813 confirms or refutes these** — no board photos or electrical schematics occur in this range.
